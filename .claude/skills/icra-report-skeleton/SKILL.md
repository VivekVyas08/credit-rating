# Report skeleton (Step 16)

1. Copy the contents of `SKELETON.md` (this folder) into `<Company>_<DD Mon YYYY>_Rating Rationale.md` in the project root.
2. Fill every `{{...}}` placeholder — numbers COPIED from the workpaper's computed output only (never retyped from notes or the anchor); qualitative claims from the fact register with sources.
3. Delete the variant blocks that don't apply (bank/NBFC/INC/CP-only) and the instruction comments.
4. Then run Step 17 (drift re-verification) as usual.

Rules that still bind while filling: headline grammar must match the Summary table; methodologies named WITH vintage; short-term ratings carry NO outlook; liquidity descriptor = conclusion of the sources-vs-claims arithmetic; every driver headline = positioning claim + consequence with 3+ verifiable specifics; sensitivities symmetric with challenges; Annexure I per Step 7b (from the annual report, never "not available").
