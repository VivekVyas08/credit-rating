# CareEdge (CARE Ratings) — reference data

Drop CareEdge / CARE Ratings source material here. Same three-part layout as ICRA (which lives at the project root).

| Folder | What to put here |
|---|---|
| `Methodology/` | CARE Ratings criteria / methodology documents (Corporate, sector criteria, Financial ratios — Non-financial sector, etc.), as `.md` or `.pdf`. |
| `Report for Reference/` | Published CARE **Rating Rationales / Press Releases** (one company per file). CRAFT source only — format, section order, house style, calibration — never a source of facts for a new report. |
| `Knowledge Base/` | CARE-specific distilled files (methodology index, sector→criteria routing map, report template with CARE's section order, rationale-construction library) — built the same way the ICRA Knowledge Base was, once enough Methodology + Report files are present. |

**Rating scale:** long-term `CARE AAA … CARE D` (with `+`/`-` modifiers AA to C); short-term `CARE A1+ … CARE A4, CARE D`. Symbols follow the SEBI-standardised structure.

**Naming convention (recommended):** `<Company>_<DD Mon YYYY>_<code>.md` for rationales, matching the ICRA convention.

Do NOT mix CARE and ICRA files in the same folder — the agency is inferred from the folder.
